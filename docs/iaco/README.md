# Documentación del algoritmo IACO

Resultados y calibración del planificador por colonia de hormigas
(`pe.pucp.paqtracker.iaco`).

| Archivo | Contenido |
|---|---|
| [`resultados.md`](resultados.md) | Informe principal: IACO v2.1 vs v3.0 sobre los 36 meses de datos, ablación de las mejoras M11–M21 y análisis de factibilidad. |
| [`barrido_2027_2028.md`](barrido_2027_2028.md) | Barrido de los meses de 2027 y 2028, donde la demanda diaria es más alta. |
| [`referencia/`](referencia/) | Resultados del prototipo Python retirado, conservados como línea base del puerto a Java. |

Estos resultados usan el dominio propio del IACO y no se pueden comparar
directamente con los del GA. La comparación en el mismo contexto está en
[`../comparacion_ga_iaco.md`](../comparacion_ga_iaco.md).

Para reproducir las corridas, ver la sección *Ejecutar el IACO* del
[README del repositorio](../../README.md).
